브루 음성 · 자막 넣기

  1. 대본을 넣고 AI 목소리(예: 송세아)로 음성 만들기 — 사진·배경음악은 넣지 않아도 됨
  2. 내보내기 → 오디오 파일(mp3 또는 wav) 저장
  3. 내보내기 → 자막 파일(srt) 저장
음성: 없음
자막: 없음
2

대본 (선택)

브루 음성을 쓸 때는 비워 둬도 됩니다. 대본에 [장면 001] 표시가 있으면 그 위치에서 사진이 바뀌고, [챕터] 표시가 있으면 유튜브 챕터가 만들어집니다. 없으면 사진 장수에 맞춰 고르게 나눕니다.

[챕터] 1부. 낡은 장부        ← 유튜브 챕터 제목 (선택)
[장면 003]                   ← 여기서 사진 3번으로 바뀜
[내레이션] 서윤희가 시집온 곳은...
[한숙자] 쌀자루는 왜 아직 그대로냐.
[서윤희|슬픔] 금방 옮기겠습니다.        ← 감정 지정
[김덕수|분노|1.5] 그만들 해라.          ← 감정 + 세기(0~2)

감정: 보통 · 기쁨 · 슬픔 · 분노 · 속삭임 · 톤업 · 톤다운 · 자동  /  태그 없는 줄은 내레이션  /  # 으로 시작하는 줄은 무시

3

사진 자동 생성 (선택 · Gemini API 키가 있을 때만)

① 인물 참고 사진 — 인물마다 얼굴 사진 1장을 정해두면 모든 장면에서 같은 얼굴로 나옵니다

② 썸네일 — 썸네일 A 는 장면 001 사진으로도 쓰입니다

③ 장면 사진 전부 만들기

만든 사진은 아래 사진 칸에 장면 번호대로 바로 들어갑니다. 마음에 안 드는 장은 아래 칸의 [다시] 를 누르세요. 한 번 만든 사진은 브라우저에 저장되어, 새로고침해도 다시 돈이 들지 않습니다.

4

영상 · 사진 넣기

맨 앞 하이라이트 영상 · 썸네일 (영상 1 → 영상 2가 맨 처음에 나오고, 끝나면 썸네일 사진과 함께 대본 낭독이 시작됩니다 · 영상 1개만 넣어도 됩니다)

장면 사진

사진 번호가 엉망일 때 — 프롬프트 내용으로 자리 맞추기 (AI가 사진을 보고 맞는 장면을 찾아 넣음 · 무료)

Flow에 붙여넣었던 장면 프롬프트 코드 블록을 그대로 아래에 붙여넣고 버튼을 누르세요. 파일 이름·번호는 무시하고, 사진에 보이는 내용과 가장 비슷한 장면에 한 장씩 넣습니다. 썸네일(001) 칸의 사진은 그대로 둡니다.

구독·좋아요 영상 (한 번 넣으면 계속 저장)

대본에서 "구독과 좋아요…" 멘트가 나오는 순간 자동으로 이 영상이 나옵니다. 매번 넣을 필요 없이 이 브라우저에 저장됩니다.
